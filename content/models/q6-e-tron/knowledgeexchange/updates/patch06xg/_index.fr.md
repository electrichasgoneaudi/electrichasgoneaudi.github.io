## 06XG

- Ce n'est pas une mise à jour en OTA, la voiture doit visiter l'atelier
- Il peut s'agir d'une mise à jour disponible uniquement dans certains pays/marchés

### Date de sortie : inconnu

- Il peut y avoir une configuration logicielle défavorable dans le module de commande de corps (HCP4). Il peut donc être parfois impossible de déverrouiller le véhicule de l'extérieur.
