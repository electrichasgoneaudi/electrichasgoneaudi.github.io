Le code couleur dans différents formats sont.

- HEX f36f21
- RGB 243 111 33
- Laboratoire 63 49 64
- CMYK 0 70 98 0
- Les données sont disponibles sur le site Web de la Commission.
- NCS S1080 Y50R
