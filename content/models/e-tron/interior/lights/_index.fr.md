## Feux intérieurs standard

Les feux intérieurs suivants sont de série sur Audi e-tron

- Module de toit avant et arrière à DEL (blanc)
- lumière du compartiment à bagages, gauche et droite (blanc)
- compartiment de rangement dans la console centrale avant (blanche)
- compartiment à gants éclairé
- Éclairage du sol en avant/arrière
- Miroir Makup avec lumière
- Lumière dans la porte arrière

## Emballage lumineux ambiant

Lumières blanches avec option id **QQ1** vous donne

- Lumières ambiantes blanches dans les zones facbriques dans les portes
- Éclairage d'Orient dans les poignées extérieures
- Lumières ambiantes blanches dans la console centrale

## Contour multicolore/paquet lumineux ambiant

Cette option avec l'option id **QQ2** vous donne.

- Lumières ambiantes blanches dans les zones facbriques dans les portes
- Éclairage d'Orient dans les poignées extérieures
- Lumières ambiantes multicolores dans la console centrale
- Lumières multicolores dans la console centrale
- Éclairage de contour dans le tableau de bord et le tableau de bord.

Les couleurs peuvent être ajustées avec 30 options de couleur par commande
