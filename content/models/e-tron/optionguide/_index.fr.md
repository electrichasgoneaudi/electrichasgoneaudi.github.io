Le guide suivant est basé sur le modèle de base. De nombreux marchés ont des options de garnitures incluses.

Voici les options les plus importantes que vous devez considérer lors de l'achat d'un e-tron

## Interface smartphone : Option ID UI1

Sans interface smartphone, vous ne pouvez pas utiliser Android Auto / Apple Carplay et ensuite utiliser des applications comme Waze ou contrôler Spotify d'une bonne manière.

[See smartphone interface for details.](/fr/models/e-tron/technology/uiandoperations/smartphoneinterface/)

## Fenêtres de confidentialité : Option ID QL5

Améliore l'apparence beaucoup et vous n'avez pas besoin de conduire autour dans un réservoir de poisson sur l'affichage.

[See windows for details](/fr/models/e-tron/exterior/windows/#privacy-glass)

![3y4](https://media.evkx.net/ehga/models/e-tron/interior/curtain/curtains.webp)

## Rideaux de fenêtres

Protège les personnes en place arrière du soleil.

[See curtain for detail](/fr/models/e-tron/interior/curtain)

## Paquet Tour : Option ID PCC

Le package de visite contient la plupart des fonctionnalités importantes de l'aide au conducteur comme [Adaptive Cruise Assist](/fr/models/e-tron/technology/drivingassistance/adaptivecruiseassist/), [Adaptive Cruise Control](/fr/models/e-tron/technology/drivingassistance/adaptivecruisecontrol/),  [Predictive efficiency assist](/fr/models/e-tron/technology/drivingassistance/predictiveefficiencyassist/), [Turn Assist](/fr/models/e-tron/technology/drivingassistance/turnassist/), [Collision avoidance assist](/fr/models/e-tron/technology/drivingassistance/collisionavoidanceassist/), [Traffic sign recognition](/fr/models/e-tron/technology/drivingassistance/trafficsignrecognition/), [Emergency Assist](/fr/models/e-tron/technology/drivingassistance/emergencyassist/)

## Paquet d'assistance latérale PCH / Paquet ville PCM

L'aide latérale n'est pas un forfait de visite partielle et est incluse dans deux forfaits d'assistants différents. [Side Assist](/fr/models/e-tron/technology/drivingassistance/sideassist/), [exit warning](/fr/models/e-tron/technology/drivingassistance/exitwarning/), [cross traffic assist rear](/fr/models/e-tron/technology/drivingassistance/crosstrafficassistrear/), [Audi Pre Sense rear](/fr/models/e-tron/technology/drivingassistance/presenserear/). Le forfait ville comprend le même, mais en outre [Audi pre sense side](/fr/models/e-tron/technology/drivingassistance/presenseside/) et [crossing assist](/fr/models/e-tron/technology/drivingassistance/crossingassist/)

![QQ2](https://media.evkx.net/ehga/models/e-tron/interior/lights/multicolors.webp)

## Éclairage ambiant multicolore: Option ID QQ2

Avec l'éclairage ambiant multicolore, le look et la sensation à l'intérieur de la voiture arrive à une autre planète.

[See ambient lighting to get convinced](/fr/models/e-tron/interior/lights/)
