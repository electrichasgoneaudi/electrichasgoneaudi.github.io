Le Audi Q5 e-tron est proposé en deux variantes, utilisant la même batterie de 83,4 kWh mais avec des puissances et une motorisation différentes.

{{< evkxfiguresized thumb="models/audi/q5_e-tron/q5_e-tron_50_quattro/exterior_b7b55_st.webp" width="1920" height="1080" title="Audi Q5 e-tron" >}}

## Audi Q5 e-tron 40

La variante d'entrée avec traction arrière et un seul moteur électrique.

| Spécification | Valeur |
|---|---|
| Puissance maximale | 150 kW (204 ch) |
| Torque | 310 Nm |
| 0–100 km/h | 9,3 s |
| Vitesse maximale | 160 km/h |
| Plage CLTC | 560 km |
| Consommation de CLTC | 15,9 kWh/100 km |
| Batterie (brut) | 83,4 kWh |
| Batterie (net) | 76,6 kWh |
| Chimie des batteries | NMC |
| Démarrer | Roue arrière |

## Audi Q5 e-tron 50 quattro

La variante de performance avec deux moteurs électriques et quattro tout-roue motrices.

| Spécification | Valeur |
|---|---|
| Puissance maximale | 225 kW (306 ch) |
| Torque | 460 Nm |
| 0–100 km/h | 6.7 s |
| Vitesse maximale | 160 km/h |
| Plage CLTC | 550 km |
| Consommation de CLTC | 16,2 kWh/100 km |
| Batterie (brut) | 83,4 kWh |
| Batterie (net) | 76,6 kWh |
| Chimie des batteries | NMC |
| Démarrer | Puissance motrices intégrales (quattro) |

| Spécification | Valeur |

| Charge maximale sur le toit | 75 kg |
| Poids maximal de la remorque (brouillé) | 1 200 kg |
| Emplacement du port de chargement | Côté arrière gauche |
