Le guide suivant est basé sur le modèle de base. De nombreux marchés ont des options de garnitures incluses.

Vous devriez lire dans le tout [option list](list) mais ci-dessous sont les options les plus importantes que vous devez considérer lors de l'achat d'un véhicule Audi Q4 e-tron.

![IU1](https://media.evkx.net/ehga/models/q4-e-tron/optionguide/iu1.webp)

## Interface smartphone : Option ID UI1

Sans interface smartphone, vous ne pouvez pas utiliser Android Auto / Apple Carplay et ensuite utiliser des applications comme Waze ou contrôler Spotify d'une bonne manière.

Actuellement, ce n'est disponible que dans le package infodivertissement avec optionID **PYX** qui inclut également la boîte téléphonique, et deux USB-C dans les sièges arrière.

[See smartphone interface for details.](../technology/uiandoperations/smartphoneinterface/)

![QL2](https://media.evkx.net/ehga/models/q4-e-tron/optionguide/ql5.webp)

## Fenêtres de confidentialité : Option ID QL5

Améliore l'apparence beaucoup et vous n'avez pas besoin de conduire autour dans un réservoir de poisson sur l'affichage.

[See windows for details](../exterior/windows/#privacy-glass)

![PYG](https://media.evkx.net/ehga/models/q4-e-tron/optionguide/pyg.webp)

## MMI Navigation plus: Option ID PYG

Avec l'option MMI Navigation Plus, vous obtenez le système de navigation MMI et le poste de pilotage virtuel. Avoir un système intégré dans Navigation donne plusieurs avantages par rapport à l'utilisation de votre téléphone.

Voir détails sur [MMI Navigation Plus](../technology/uiandoperations/navigation/) et [Virtual Cockpit](../technology/uiandoperations/virtualcockpit/)

![Matrix](https://media.evkx.net/ehga/models/q4-e-tron/technology/lights/signature1s.webp)

## Phares à DEL Matrix

Avec les phares à LED Matrix vous obtenez beaucoup de lumières améliorées sur la route de campagne. En outre les phares à LED Matrix est une exigence pour obtenir la bande rouge fraîche à l'arrière.

Lire plus à propos de [Matrix LED Headlights](../technology/lights/#matrix-headlights).

## Assistantpackage Pro: Option ID PY7

Le paquet assistant pro contient la plupart des fonctionnalités importantes driver assist comme [Adaptive Cruise Assist](../technology/drivingassistance/adaptivecruiseassist/), [Adaptive Cruise Control](../technology/drivingassistance/adaptivecruisecontrol/)  et [Parking System Plus](../technology/drivingassistance/parkingsystemplus/)

## Paquet de sécurité plus: Option ID PYU

L'assistance latérale n'est pas une partie Assistantpackage Pro, mais est incluse dans le paquet de sécurité plus le paquet. [Side Assist](../technology/drivingassistance/sideassist/), [exit warning](../technology/drivingassistance/exitwarning/), [cross traffic assist rear](../technology/drivingassistance/crosstrafficassistrear/), [Audi Pre Sense rear](../technology/drivingassistance/presenserear/).

![QQ2](https://media.evkx.net/ehga/models/q4-e-tron/optionguide/qq2.webp)

## Éclairage ambiant multicolore: Option ID QQ2

Avec l'éclairage ambiant multicolore, le look et la sensation à l'intérieur de la voiture arrive à une autre planète.

[See ambient lighting to get convinced](../interior/lights/)
