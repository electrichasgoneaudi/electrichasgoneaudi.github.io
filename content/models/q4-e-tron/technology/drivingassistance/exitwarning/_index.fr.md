 Le système utilise des voyants LED dans les panneaux de porte. Dans une situation jugée dangereuse, les LED clignotent et rouge clair. Les LEDs de l'assistance latérale Audi sont également allumées dans le rétroviseur extérieur pertinent. L'avertissement de sortie reste actif environ trois minutes après l'allumage est éteint.

Ce système est basé sur les capteurs radar de l'assistance latérale d'Audi, qui surveillent les zones derrière le véhicule et vers les côtés à l'arrière. Selon le modèle, l'avertissement de sortie est prolongé par une fonctionnalité supplémentaire : Si le système est actif, l'ouverture des serrures électroniques est retardée d'environ une seconde.

Ceci fait partie du paquet sécurité plus avec l'option id **PYU**
