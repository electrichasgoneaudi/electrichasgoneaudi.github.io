En Europe, Audi utilise [Cubic Telecom](https://audi.cubictelecom.com/en/) pour l'abonnement intégré.

Pour les services ci-dessous, le montant des données est inclus. La longueur varie d'un pays à l'autre, mais est typique de 3 ans.

Si vous avez besoin de données pour la zone Wifi ou la radio en ligne dans la voiture, vous devez acheter un paquet de données supplémentaires ou utiliser votre propre carte si votre modèle supporte cela.
