Ouverture confort des vitres

Comment désactiver l'ouverture de toutes les vitres avec la clé

Last updated Sep 30, 2026
Audi Q6 e-tron Variants Dimensions Exterior Specifications Transportation Capabilities Drivetrain Interior Technology Model Year changes Multimedia Reviews Options Guide Knowledge Exchange

Cette fonction est incluse avec l’option Clé confort. Elle vous permet de maintenir enfoncé le bouton de déverrouillage de la clé du véhicule pour ouvrir les quatre vitres simultanément. L’ouverture s’arrête dès que vous relâchez le bouton. Si vous le maintenez enfoncé assez longtemps, les vitres s’ouvriront complètement.

De la même manière, vous pouvez également maintenir enfoncé le bouton de verrouillage pour refermer les vitres.

Bien qu’il s’agisse d’une fonction pratique, elle comporte un certain risque si votre clé se retrouve coincée dans un sac ou est actionnée par inadvertance – par exemple si la voiture est garée à l’extérieur d’un chalet sous la pluie et le vent. Il est très désagréable de retrouver son véhicule plein d’eau ou de neige le lendemain matin.

Heureusement, il existe un moyen simple d’éviter cela. Vous pouvez désactiver cette fonction dans le MMI. Malheureusement, elle est activée par défaut, c’est donc un réglage que la grande majorité des utilisateurs devrait modifier immédiatement.

Voici comment procéder :

  • Sélectionnez Réglages & Service dans le menu principal

  • Sélectionnez Verrouillage centralisé

  • Désactivez la fonction ‘Ouverture confort des vitres’

  • Voilà – en espérant que cela vous évitera ce genre de surprise à l’avenir
