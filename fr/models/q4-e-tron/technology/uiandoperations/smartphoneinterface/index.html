Audi Q4 e-tron smartphone Interface

Avec l'option Interface Smartphone sur Audi Q4 e-tron, vous étendez votre smartphone au système MMI

Dernière mise à jour 30 sept. 2026
Audi Q4 e-tron Variantes Dimensions Extérieur Spécifications Intérieur Capacités de transport Groupe motopropulseur Technologie Examens Multimédia Échange de connaissances Guide des options

Avec l’interface smartphone Audi avec option id IU1 vous avez la possibilité d’utiliser Apple Carplay ou Android Auto dans votre système MMI.

Cela vous donne accès à de nombreuses applications utiles comme Spotify et Waze directement dans MMI.

L’image suivante montre comment Waze avertit les utilisateurs d’une caméra de vitesse dans un e-tron Audi.

Android Auto et Apple Carplay sont pris en charge par câble et sans fil sur Audi Q4 e-tron.

Actuellement, cette option n’est disponible qu’en tant que partie de la Infotainment package avec l’option id PYX, la Infotainment small package avec l’option id PY3 et le MMI Navigation Pro package avec l’option ID PYH
