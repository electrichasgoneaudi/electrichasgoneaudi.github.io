Audi e-tron guide des options

Audi e-tron a tellement d'options qu'il est presque impossible d'obtenir la vue d'ensemble. Nous essayons de vous aider à sélectionner les options les plus importantes.

Le guide suivant est basé sur le modèle de base. De nombreux marchés ont des options de garnitures incluses.

Voici les options les plus importantes que vous devez considérer lors de l’achat d’un e-tron

Interface smartphone : Option ID UI1

Sans interface smartphone, vous ne pouvez pas utiliser Android Auto / Apple Carplay et ensuite utiliser des applications comme Waze ou contrôler Spotify d’une bonne manière.

See smartphone interface for details.

Fenêtres de confidentialité : Option ID QL5

Améliore l’apparence beaucoup et vous n’avez pas besoin de conduire autour dans un réservoir de poisson sur l’affichage.

See windows for details

Rideaux de fenêtres

Protège les personnes en place arrière du soleil.

See curtain for detail

Paquet Tour : Option ID PCC

Le package de visite contient la plupart des fonctionnalités importantes de l’aide au conducteur comme Adaptive Cruise Assist, Adaptive Cruise Control, Predictive efficiency assist, Turn Assist, Collision avoidance assist, Traffic sign recognition, Emergency Assist

Paquet d’assistance latérale PCH / Paquet ville PCM

L’aide latérale n’est pas un forfait de visite partielle et est incluse dans deux forfaits d’assistants différents. Side Assist, exit warning, cross traffic assist rear, Audi Pre Sense rear. Le forfait ville comprend le même, mais en outre Audi pre sense side et crossing assist

Éclairage ambiant multicolore: Option ID QQ2

Avec l’éclairage ambiant multicolore, le look et la sensation à l’intérieur de la voiture arrive à une autre planète.

See ambient lighting to get convinced
